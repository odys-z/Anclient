# Registry Client

A web client of [semantic-jserv](https://github.com/odys-z/semantic-jserv), built on
[@anclient/anreact](https://github.com/odys-z/Anclient/tree/master/js/anreact) and
[@anclient/semantier](https://github.com/odys-z/Anclient/tree/master/js/semantier),
generated by Anclient/examples/example.js/create-anapp.py.

## Build

```
    cd ..  && npm install  # once, in examples/example.js: the shared node_modules
    cd registry.ts
    npm install            # links @anclient/*, see below
    npm run build          # or: npm run watch / npm run release
```

webpack and babel come from ../node_modules, installed by ../package.json, which has no
@anclient/* packages: each project installs its own. The legacy
projects, north-star and curriculum, install @anclient/anreact 0.7.x with ag-grid 33 in their own
folders (album already did), so no `--legacy-peer-deps` is needed.

This project's @anclient/anreact & @anclient/semantier are linked to the sources of this Anclient
checkout (anreact 0.8.0, on React 19 and MUI 9):

```
    "@anclient/anreact"  : "file:../../../js/anreact",
    "@anclient/semantier": "file:../../../js/semantier",
    "react", "react-dom" : "^19.3.1",
    "@mui/material", "@mui/icons-material": "^9.5.0",
    "@emotion/react", "@emotion/styled", "tss-react",
    "js-sha256"          : "^1.0.0"
```

npm doesn't install the dependencies of linked sources, so the ones needed are listed here too:
React, MUI, emotion and tss-react for anreact, and js-sha256 for semantier. (anreact 0.8.0 has no
ag-grid widgets; the legacy projects get them with anreact 0.7.x.) They are resolved here first (webpack.config.js,
resolve.modules), so the React 17 / MUI 4 of the legacy projects are never bundled.

React is bundled (React 19 has no UMD builds for `<script>` tags).

`npm install` makes node_modules/@anclient/* symlinks to ../../../js/*. So this client builds
with the current sources, while other projects, e.g. album, keep their own npm versions.
To build with a published version instead, change them to e.g. "^0.8.0" and npm install.
../diff-anclient.py lists which version each project uses, and compares them.

`npm run tsc` type-checks src/. Since anreact & semantier are TypeScript sources,
it also reports errors inside them; those don't affect the webpack build.

Bundles are written into web-dist/: `registry.ts.min.js` (main page) and `login.min.js`.
Both are UMD bundles exposing the global `registryTs`.

## Server

The jserv is the registry central, Acadynamo/Semantic-Network, registration/jserv, branch dev
(settings.json: port 8999, protocolRoot regist-central). Its menu.serv answers the menu of
dataset sk `sys.menu.central` (src/app.tsx, `<Sys menu=...>`), from table a_functions.

Jserv urls are loaded from web-dist/private/host.json (not committed), falling back to
web-dist/github.json:

```
    { "host": "http://localhost:8999/regist-central" }
```

Page parameter `?serv=<key>` selects one of the keys.

The function uri of this app is `/sys/registry.ts`. The server must map it to a connection
in WEB-INF/connects.xml, table conn-uri. The central's rule `/*` covers it:

```
    <c>
        <uri>/*</uri>
        <conn>sys-sqlite</conn>
    </c>
```

## Run

Serve web-dist/ with any static http server, e.g.

```
    cd web-dist && python3 -m http.server 8888
```

then open http://localhost:8888/login.html. The central allows CORS with settings.json/allowOrigins.

## Structure

| file | what |
|---|---|
| src/app.tsx | App: AnContext, Sys menu frame, error handler; `registryTs.App.bindHtml()` |
| src/login-app.tsx | LoginApp: login form, session persisted into localStorage |
| src/common/ports.ts | project's jserv ports |
| src/views/home.tsx | landing page, linked to menu url /home |
| src/views/org-domains.tsx | Domains, menu url /org/domains; OrgDomainsTier |
| src/views/domain-details.tsx | domain dialog: creates with domx.serv (synodes planned by the central), edits with community.serv |
| src/common/registry.ts | requests / replies of the central's tiers: RegistReq, DomxReq, ... |
| web-dist/res-vol/lang.json | translations used by `L()` |

To add a page: write a `CrudCompW` component in src/views, link it in App's
`SysComp.extendLinks()`, and add a menu item (App.menuTree, or the server's menu dataset).
